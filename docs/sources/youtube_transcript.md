# YouTube transcripts

[FlashData](https://flashdata.dev) · [API documentation](https://flashdata.dev/docs/sources/youtube_transcript)

Read an existing automatic caption track by default. Output includes `segments` with second-based `start` and `end`, `fullText`, and track metadata. This endpoint does not transcribe missing tracks.

## Example

```python
import os
from flashdata import FlashData

with FlashData(api_key=os.getenv("FLASHDATA_API_KEY")) as client:
    response = client.youtube.transcript("dQw4w9WgXcQ", language="en", auto=False)
    for track in response["results"]:
        print(track["languageCode"], track["isAutoGenerated"])
        for segment in track.get("segments", [])[:3]:
            print(segment["start"], segment["end"], segment["text"])
```

Run `python examples/youtube_transcript.py dQw4w9WgXcQ --output artifacts/youtube_transcript.json` from the checkout. Use `--help` for options. The command consumes credits.

## Parameters

`video_id` is required. Source options are keyword arguments, or entries in `params` when using `queries`. Data helpers default to realtime; pass `mode="async"` for background work. `timeout` controls the HTTP request.

JSON is the default. Use `accept="text/plain"` for text, or `respond_with="markdown"`
for Markdown content in realtime results. For background work, choose Markdown when
reading the completed result. See [response formats](../response-formats.md).

| Option | Type / constraints | Default |
| --- | --- | --- |
| `language` | string or array of 1–10 distinct codes | `en-orig`, then `en` |
| `auto` | boolean | true |

Omit `language` to prefer `en-orig`, falling back to `en` and returning one track.
A string such as `"en"` selects that exact language and keeps the single-track response.
An array of 1–10 distinct codes, including a one-element array, returns `tracks` and
`errors` inside each result. Each code must match `[A-Za-z0-9-]{1,35}`.

Read successful tracks even when another language fails. Each error includes
`languageCode`, `code` (`language_unavailable` or `retrieval_failed`) and `message`.
Both lists preserve request order; if all requested languages fail, `tracks` is empty.
Video-level extraction failures still fail the request. Explicit languages never fall
back to other languages. `auto` selects one caption source for the whole request:
`true` for automatic captions, `false` for uploaded captions. It defaults to `true`
for transcripts and `false` for captions, with no switch between the two.


## Multiple languages

```python
import os
from flashdata import FlashData

with FlashData(api_key=os.getenv("FLASHDATA_API_KEY")) as client:
    response = client.youtube.transcript("aircAruvnKk", language=["en", "es"])
    for result in response["results"]:
        for track in result.get("tracks", []):
            print(track["languageCode"], track["fullText"])
        for error in result.get("errors", []):
            print(error["languageCode"], error["code"], error["message"])
```

The same language array works with realtime, async, batch and bulk requests.
