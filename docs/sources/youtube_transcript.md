# YouTube transcripts

[FlashData](https://flashdata.dev) · [API documentation](https://flashdata.dev/docs/sources/youtube_transcript)

Read an existing automatic caption track by default. Output includes `segments` with second-based `start` and `end`, `fullText`, and track metadata. This endpoint does not transcribe missing tracks.

## Example

```python
import os
from flashdata import FlashData

with FlashData(api_key=os.getenv("FLASHDATA_API_KEY")) as client:
    response = client.youtube.transcript("dQw4w9WgXcQ", language="en", auto=False)
    for track in response["results"]:
        print(track["languageCode"], track["isAutoGenerated"])
        for segment in track.get("segments", [])[:3]:
            print(segment["start"], segment["end"], segment["text"])
```

Run `python examples/youtube_transcript.py dQw4w9WgXcQ --output artifacts/youtube_transcript.json` from the checkout. Use `--help` for options. The command consumes credits.

## Parameters

`video_id` is required. Source options are keyword arguments, or entries in `params` when using `queries`. Data helpers default to realtime; pass `mode="async"` for background work. `timeout` controls the HTTP request.

JSON is the default. Use `accept="text/plain"` for text, or `respond_with="markdown"`
for Markdown content in realtime results. For background work, choose Markdown when
reading the completed result. See [response formats](../response-formats.md).

| Option | Type / constraints | Default |
| --- | --- | --- |
| `language` | string; pattern `^[A-Za-z0-9-]+$` | "en" |
| `auto` | boolean | true |

`auto` defaults to `True` for transcripts and `False` for captions. The example selects an uploaded English track explicitly, so it can be run on the same video as the captions example. Language selection has no automatic translation or fallback.
