# YouTube captions

Read an existing uploaded caption track by default. Check `languageCode` and `isAutoGenerated` before consuming `segments` or `fullText`. Select a track that exists on the video.

## Example

```python
from flashdata import FlashData

with FlashData() as client:
    response = client.youtube.captions("dQw4w9WgXcQ", language="en", auto=False)
    for track in response["results"]:
        print(track["languageCode"], track["isAutoGenerated"])
        for segment in track.get("segments", [])[:3]:
            print(segment["start"], segment["end"], segment["text"])
```

Run `python examples/youtube_captions.py dQw4w9WgXcQ --output artifacts/youtube_captions.json` from the checkout. Use `--help` for options. The command consumes credits.

## Parameters

`video_id` is required. Source options are keyword arguments, or entries in `params` when using `queries`. Data helpers default to realtime; pass `mode="async"` for background work. `timeout` controls the HTTP request.

| Option | Type / constraints | Default |
| --- | --- | --- |
| `language` | string; pattern `^[A-Za-z0-9-]+$` | "en" |
| `auto` | boolean | false |

`auto` defaults to `True` for transcripts and `False` for captions. The example selects an uploaded English track explicitly, so it can be run on the same video as the captions example. Language selection has no automatic translation or fallback.
