# Youtube Captions

Wire source: `youtube_captions`. Helper: `client.youtube.captions`. Required input: `video_id`.
Modes: realtime, async, batch. [Product API reference](https://flashdata.dev/docs/sources/youtube_captions).

## Runnable example

Run from the repository root after setting `FLASHDATA_API_KEY`:

```sh
python examples/youtube_captions.py
```

```python
from flashdata import FlashData

with FlashData() as client:
    response = client.youtube.captions('dQw4w9WgXcQ', language='en', auto=False)
    print(response)
```

## Parameters

The helper takes the main input and the following source options. Generic query methods
put options inside `params`. Omitted defaults are resolved by the API, not inserted by
the SDK. Request options select mode/callback separately from source parameters.

| Parameter | Type | Server/catalog default | Meaning / bounds |
| --- | --- | --- | --- |
| `language` | string | "en" |  Must match the documented format. |
| `auto` | boolean | false | true selects automatically generated captions; false selects manually provided captions. Does not fall back between the two. |

For `filters`, see the complete property definitions in [source-contract.json](../../source-contract.json).
The requested track must already exist. `auto` selects automatic versus uploader-provided captions without fallback, transcription or translation.
