# Getting started

## Install from source

In the `flashdata-python` checkout, create an environment and install the package:

```sh
python -m venv .venv
# macOS / Linux
source .venv/bin/activate
python -m pip install .
```

On PowerShell, activate with `.venv\Scripts\Activate.ps1`, then run the same pip command.
Use Python 3.10 or newer. Development dependencies are optional; applications only need
the package's runtime dependencies. Source installation is supported before the PyPI release.

## Authenticate

Get an API key from your [FlashData account](https://flashdata.dev) and pass it as
`api_key` when creating a client. The examples use `os.getenv("FLASHDATA_API_KEY")`
to read it from your process environment:

```sh
export FLASHDATA_API_KEY="YOUR_API_KEY"
```

```powershell
$env:FLASHDATA_API_KEY = "YOUR_API_KEY"
```

`api_key` accepts a string, whether read from the environment or supplied by your secret
manager. Authentication works the same way with `FlashData` and `AsyncFlashData`.
For optional automatic environment lookup and `.env` configuration, see
[client configuration](client.md#api-keys).

## Make a request

```python
import os
from flashdata import FlashData

with FlashData(api_key=os.getenv("FLASHDATA_API_KEY")) as client:
    response = client.google.search("coffee", num=5)
    print("Charged credits:", response["usage"]["credits"])
    for payload in response["results"]:
        for hit in payload.get("organic", []):
            print(hit["title"], hit["link"])
```

Context managers close HTTP connection pools. Keep one client for multiple requests
instead of creating a client for every call. See [async and configuration](client.md).

## Understand the response

A realtime response has `source`, `status` (`done`), `created_at`, `usage`, and `results`.
The `results` array wraps provider payloads; it is not a universal flat hit list.

| Source | Read from each item of `response["results"]` |
| --- | --- |
| Google web / images / news / shopping / videos / places | `organic` / `images` / `news` / `shopping` / `videos` / `places` |
| YouTube search and extended search | `results` list of matching entities |
| Metadata | `videoId`, `title`, `duration`, `transcriptLanguages`, optional formats/chapters |
| Transcript and captions | `segments`, `fullText`, `languageCode`, `isAutoGenerated` |
| Channel | channel properties and `videos` list |
| Suggestions | the item is itself a list of strings |
| License check | `videoId`, `permitted` labels |

Source payload fields depend on upstream availability. Optional lists may be empty and
some fields may be absent. The SDK preserves additional fields. It does not convert dates,
prices, durations or currency strings into inferred values. Source guides explain their
field names. Failed requests raise [exceptions](errors.md).

## Choose an execution mode

- **Realtime:** return results directly; supported for all data sources.
- **Background:** pass `mode="async"`, save the returned ID, then read [job results](jobs.md).
- **Batch:** submit a list of different source requests; each accepted item becomes a job.
- **Bulk:** upload an ID file for one supported YouTube source, then export result parts.

Queries and each paginated page consume credits. Free account reads expose current
pricing and limits. Start with [account discovery](account.md) before large workloads.
Media download is background-only and delivers to [your cloud storage](storage.md).
